# EpayFC - Plateforme de Vente et d'Enchères en Ligne

EpayFC est une application web de type marketplace permettant aux utilisateurs de publier des annonces pour vendre des objets. Le projet intègre un double système de commercialisation : la vente directe (achat immédiat) et le système d'enchères.

Projet réalisé dans un cadre académique.

## Fonctionnalités principales

- **Gestion des annonces :** Création, modification et suppression d'annonces.
- **Double mode de vente :**
  - Achat immédiat au prix fixé par le vendeur.
  - Système d'enchères avec suivi des offres.
  - Mode hybride combinant les deux options.
- **Parcours utilisateur :** Navigation, recherche et filtrage parmi les annonces disponibles.
- **Authentification :** Inscription, connexion et gestion du profil utilisateur.

## Stack technique

- Langages : PHP, JavaScript
- Base de données : MySQL
- Gestion de version : Git

## Installation et Lancement

1. Cloner ou placer le dossier du projet directement dans le répertoire `htdocs` de XAMPP (sous le nom `prwb_2526_f05`).
2. Lancer XAMPP et démarrer les services **Apache** et **MySQL**.
3. Ouvrir un navigateur et accéder à l'URL d'initialisation :
   `http://localhost/prwb_2526_f05/setup`
   Cette page configure et peuple automatiquement la base de données avec des données de test.
4. Cliquer sur le bouton "Retour à l'index" pour être redirigé vers la page de connexion et commencer à utiliser l'application.
